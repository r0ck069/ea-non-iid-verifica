Verifica sorgenti non-IID (SP 800-90B)

Carica il file grezzo di una sorgente, anche se contiene metadati. La pagina estrae i simboli, stima la min-entropia con i dieci stimatori del NIST e produce la sorgente estratta e il rapporto di verifica.

Stima, non certificazione. Il risultato misura la min-entropia dei dati caricati. Non dice se la sorgente è adatta né sostituisce la valutazione di chi la usa.

1. Autotest del calcolo

In esecuzione…

Confronta il calcolo con i file di riferimento ufficiali del NIST incorporati (rand1_short, rand4_short, rand8_short, dal repository EntropyAssessment, tolleranza 1e-6). Verifica il calcolo, non la sorgente.

2. File grezzo

Nessun file caricato.
Anteprima dei primi byte o caratteri







3. Estrazione











La soglia è un criterio di scelta, da fissare in base all'uso previsto: il valore predefinito 1,00 è il più severo. Il verdetto usa la min-entropia per bit, cioè il risultato finale diviso per i bit per simbolo.


Per byte, esadecimali e decimali si usano i bit più bassi di ogni valore. Per WAV PCM a 8, 16, 24 o 32 bit e WAV in virgola mobile a 32 o 64 bit si legge il blocco data campione per campione (anche WAVE_FORMAT_EXTENSIBLE). Il calcolo su file grandi può richiedere diversi minuti.

5. Output








La sorgente estratta contiene un byte per simbolo, con valori compresi tra 0 e 2^bit−1. È il file candidato da concatenare ad altre sorgenti. Scaricalo solo se il verdetto è verde.
